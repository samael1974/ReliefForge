RELIEFFORGE V8.4 - ISTRUZIONI
=============================

PER L'UTENTE FINALE
-------------------
1. Scarica ReliefForge-Setup-8.4.0.exe (dalla pagina Releases su GitHub).
2. Doppio clic sul file e segui la procedura guidata.
3. Avvia ReliefForge dall'icona sul Desktop o dal menu Start.

Non servono Node.js, pnpm o altri strumenti: l'installer contiene tutto.

Nota: alla prima esecuzione Windows SmartScreen puo' mostrare un avviso
perche' l'installer non e' firmato digitalmente. Clicca su
"Ulteriori informazioni" e poi "Esegui comunque".

PER LO SVILUPPATORE: CREARE L'INSTALLER
---------------------------------------
Doppio clic su CREA_SETUP_EXE.bat. Lo script:
  1. installa le dipendenze (pnpm install)
  2. compila il frontend (vite build --base=./)
  3. crea release\ReliefForge-Setup-8.4.0.exe (electron-builder, NSIS)
Log completo in crea_setup_log.txt. Non chiudere la finestra nera
finche' non compare FATTO!

SVILUPPO
--------
pnpm install
pnpm electron:dev     (app desktop con dev server e DevTools)

PROFILO CONSIGLIATO
-------------------
- Modello AI: Massima (se gia' scaricato e il PC lo regge).
- Depth: Ritratto V8.1 per volti; Scultura V8.3 per statue e oggetti.
- Mesh: Fine V8.3.
- Decimazione manuale: 1x; aumentarla solo per alleggerire.
